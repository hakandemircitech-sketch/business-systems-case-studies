## Yaklaşım

**İhtiyacı anla → sınırları tanımla → mimariyi kur → doğrula → insan kontrolüyle işlet.**

Prototip, araştırma, doğrulanmış entegrasyon ve canlıya alınmış hizmet birbirinden ayrılır. Geçmiş test kaydı, sonraki kod değişikliklerinin de aynı testlerden geçtiği anlamına gelmez.

## Kapsam ve paylaşım politikası

- Vaka açıklamaları, sadeleştirilmiş şemalar ve doğrulama durumu paylaşılır.
- Özel depo içeriği, kaynak kodu, prompt metinleri, kullanıcı/lead verileri, gizli yapılandırmalar ve anahtarlar paylaşılmaz.
- Bu portföyün kendisi çalışan bir servis ya da kamuya açık bir API değildir.
- Yeni bir sonuç doğrulanmadan başarı veya üretim güvencesi olarak duyurulmaz.
